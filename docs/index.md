# fdtd.py

fdtd.py is a Python library for finite-difference time-domain (FDTD)
electromagnetic simulations.

## Install

```bash
pip install fdtd.py
```

## Get started

The [README example](https://github.com/tiagovla/fdtd.py#example) shows a
voltage source, resistor, and field detectors in a simulation. See the
[API reference](api.md) for the package's public classes and their parameters.
